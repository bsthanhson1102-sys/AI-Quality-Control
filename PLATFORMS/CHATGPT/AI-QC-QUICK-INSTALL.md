# AI-QC TEAM — QUICK INSTALL (NO API)

## Recommended setup
Use a dedicated ChatGPT Project named **AI-QC — Expert Team**. This keeps the operating instructions and reference files together. No API key, server, Docker or paid external model is required.

## Step 1 — Create the Project
In ChatGPT, create a Project named **AI-QC — Expert Team**. If project creation or project instructions are unavailable on the current plan, use Custom Instructions instead.

## Step 2 — Install the operating instructions
Copy the complete contents of [AI-QC-TEAM-INSTRUCTIONS.md](AI-QC-TEAM-INSTRUCTIONS.md) into the Project instructions. If using Custom Instructions, paste the same content there; if the field has a length limit, use the compact core: four sequential expert perspectives, Judge, 90/100 gate, maximum four rounds, evidence-first medical/academic checks, and honest disclosure that all four perspectives use one model.

## Step 3 — Add the reference files
Upload the following current files from this repository to the Project:
- REGISTRY/skills-registry.yml
- CORE/quality-control.md
- CORE/skill-router.md
- CORE/multi-expert-orchestration.md
- CORE/auto-improvement.md
- CORE/final-audit.md
- CORE/skill-lifecycle.md
- All active SKILLS/*/SKILL.md files relevant to the user's work

For medical/academic work, attach the actual course materials or source documents to the conversation as needed. Do not rely on a summary if the original file is available.

## Step 4 — Start using it
The user can simply ask:
- "Viết bài Facebook giới thiệu dịch vụ..."
- "Giải thích câu hỏi y khoa này..."
- "Kiểm tra tài liệu học tập này..."
- "Thiết kế quy trình..."
No special command or expert names are needed.

## Step 5 — Keep Skills updated
When a Skill or Registry changes on GitHub, refresh the corresponding Project files. Existing Project uploads and already-open chats do not automatically update from GitHub. For important tasks, retrieve the latest Registry and relevant Skill through an available GitHub connection before claiming current-version use.

## What this no-API setup can and cannot do
It CAN provide four differentiated expert perspectives, structured judging, evidence checks, revisions, a final audit and modular Skill-based workflows inside ChatGPT.
It DOES NOT create four separate AI models, guarantee parallel processing, run background agents, or automatically sync GitHub files without an available integration and explicit setup.
Use the normal ChatGPT model and tools available in the current session. This is the simplest low-cost starting point.
