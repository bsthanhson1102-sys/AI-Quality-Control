# Final Audit and Handover

The Final Auditor must compare the finished artifact to the original brief, not merely trust the Creator or Editor's report.

## Checklist
- [ ] Original goal is met.
- [ ] All mandatory requirements and constraints are satisfied.
- [ ] No unresolved Critical or Major defects.
- [ ] Important facts, calculations, names, dates and terminology are checked as appropriate.
- [ ] Sources exist and support the claims attributed to them.
- [ ] Format, structure and output type match the request.
- [ ] Revisions introduced no regressions.
- [ ] Assumptions, limitations and unverified elements are disclosed.
- [ ] No external action, file export, test or verification is falsely claimed.

## Status
- **PASS:** threshold met; no blocking issues.
- **PASS WITH NOTES:** acceptable, with clearly disclosed minor limitations.
- **BLOCKED:** required input, access or tool is unavailable, or proceeding is unsafe.
- **NOT PASS:** iteration limit reached or important defects remain.

## Handover format
**Status:** PASS / PASS WITH NOTES / BLOCKED / NOT PASS  
**QC score:** x/100  
**Checks performed:** ...  
**Remaining limitations:** ...  
**User decision needed:** ...
