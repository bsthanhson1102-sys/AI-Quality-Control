# Role and Skill routing

| Task | Primary | Conditional secondary | Decision |
|---|---|---|---|
| Video concept, director, storyboard, shot list, edit plan, video QA | video-master | content-master for marketing scripts; image-master for new/edit stills | Default |
| Video sales script only | content-master | video-master when shot/timing production is needed | Script deliverable |
| Edit supplied footage | video-master | content-master only if message/script revision is needed | Do not force content |
| Thumbnail or still visual | image-master | content-master only for marketing copy | Image deliverable |
| Medical/aesthetic claims | task primary | research-master for substantive independent evidence | Check privacy, consent and advertising risk |

**Isolation:** AI-VIDEO-LUMORA owns its briefs, routing and deliverables; Content Master remains canonical and available for unrelated marketing. Do not duplicate or edit `SKILLS/content-master/SKILL.md`, `SKILLS/video-master/SKILL.md`, `SKILLS/image-master/SKILL.md` to set up this module.

**Role sequence:** Producer -> [Content Strategist and Director as needed] -> Creative Judge -> Director/Scriptwriter -> Image Designer as needed -> Editor/Sound/Subtitles -> Critic -> Editor correction -> Re-check -> Final Auditor.

Use existing CORE rules as the final authority. Distinguish SELECTED / LOADED / APPLIED / VERIFIED / NOT NEEDED / BLOCKED for each Skill. Four perspectives in one model are not four independent models.
